project. Cropped and re-compressed for web delivery; no content altered.

## Licence notes

- **Public domain / CC0** — no attribution legally required. Given anyway.
- **CC BY** / **CC BY-SA** — attribution required, and for the ShareAlike images any
  modified copy must carry the same licence. The site states this on the About page.

## Source pages

Original files are on Wikimedia Commons. The exact file page for each is recorded in
`assets/img/credits.json` under `page`, and that file is what the site renders — so the
attribution shown to a reader is generated from the same record, not typed by hand.

## Reproducing the processing

The crop, resize, blur and compression in this directory were produced with Pillow.
Because CC BY-SA requires modified copies to keep the same licence, the processed
files remain under the licence of their source photograph.
